What You Need Before Registering

Only a few things are required, but each one matters later.

  • a mobile number that you own and can receive SMS on;
  • being at least 18 years old;
  • a password you have not used on other sites;
  • your real name, spelled the same way as on the documents you may later use for verification;
  • a stable internet connection for the SMS step.

The phone number is the core of the account. It is used for confirmation codes and for recovering access, so a borrowed or temporary number causes problems the first time a code has to be entered.

Step-by-Step Registration

The form is the same on the website and in the app; the order of the fields can differ slightly. The steps below follow the order the platform uses.

  1. Open NK101 and tap the gold "Register" button in the header;
  2. Choose a username and create a password;
  3. Enter your Nepali mobile number and the other details the form asks for;
  4. Type in the verification code sent by SMS;
  5. Log in and open the cashier.

After the last step the account opens immediately. There is nothing to wait for by e-mail.

Login and Password Recovery

Login uses the username and password; the phone number is for verification and recovery. The "Forgot?" link next to the password field starts recovery: enter the registered number, receive a code and set a new password. If the number itself is lost, contact support with the account details. Do not open a second account, because duplicate profiles are against the rules and complicate withdrawals.

Account Rules to Know

Among the terms accepted at registration, a few have practical consequences.

  • one account per person; duplicates can be closed;
  • players must be 18 or older;
  • the details must belong to the account holder, because withdrawals go to the same person;
  • verification can be requested at any time, usually before a large withdrawal.
