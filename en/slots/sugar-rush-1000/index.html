How Sugar Rush 1000 Works

Each spin drops 49 symbols onto the 7x7 grid. A cluster of five or more identical candies touching sideways or vertically pays; the winning symbols are removed and new ones tumble in, which can create more clusters in the same spin. The chain continues until no new cluster forms. There are no paylines and no wild symbol; the size of the cluster and the symbol type decide the payout.

Multiplier Spots

This is the game's signature feature. When a winning symbol is removed, its position on the grid is marked. If a second winning symbol is removed from the same spot in the same spin sequence, a x2 multiplier appears; each further removal doubles it - x4, x8, x16 - up to x1,024. The multiplier applies to any cluster covering that position, and when a cluster covers several spots their values add together. In the base game the spots reset with every new spin; in free spins they stay for the whole bonus.

Free Spins

Three or more scatter symbols (the lollipop) anywhere on the grid trigger free spins. Landing three or more scatters again adds spins on the same scale. This is where the 25,000x maximum is realistically reached.
